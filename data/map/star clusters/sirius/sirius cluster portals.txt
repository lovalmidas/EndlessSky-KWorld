# Clusters link to systems via two one-way 'wormholes'.
# The reason they are on-way is to provide each direction its own name. E.g. Sirius Cluster <-> Sirius
# Name format for easier reference:
#	KW.WH.<x>.<nnn>.*.<name>			Wormhole, cluster enter to subsystem
#	KW.WH.<x>.***.*.<name>				Wormhole, subsystem exit to cluster
#	KW.<x>.<nnn>.*.<name>				Planet, cluster enter to subsystem
#	KW.<x>.<nnn>.~.<name>				Planet, subsystem exit to cluster

# Write portal 'planets' and wormhole definitions here
